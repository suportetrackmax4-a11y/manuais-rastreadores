Configuração — Comandos de configuração do MT2000 versões 1.3.x

Comando de configuração de comunicação (APN e URL do servidor):

Para configurar APN e URL primário e secundário:

SET NTW=apn_da_operadora:usuario_apn:senha_apn:ip_ou_dns_servidor_primario:porta_servidor_primario:ip_ou_dns_servidor_secundario:porta_servidor_secundario

Exemplo usando DNS no primário e IP secundário (pode ser usado DNS e IP em ambos URL´s, primário e secundário):

*SET NTW=allcom.vivo.com.br:vivo:vivo:mbxlabcps.ddns.net:80569:187:11:203:81:80569*

Neste exemplo temos:

  • APN = allcom.vivo.com.br
  • usuário da APN = vivo
  • senha da APN = vivo
  • dns do servidor primário = mbxlabcps.ddns.net
  • porta do servidor primário = 80569
  • IP do servidor secundário = 187:11:203:81
  • porta do servidor secundário = 80569

Para ler as configurações do comando NTW:

*GET NTW*

Para configurar apenas o URL primário:

SET URL=ip_ou_dns_servidor_primario:porta_servidor_primario

Exemplo:

*SET URL=mbxlabcps.ddns.net:80569*

Neste exemplo:

  • dns do servidor primário = mbxlabcps.ddns.net
  • porta do servidor primário = 80569

Para configurar apenas o APN:

SET APN=apn_da_operadora:usuario_apn:senha_apn

Exemplo:

*SET APN=allcom.vivo.com.br:vivo:vivo*

Neste exemplo:

  • APN = allcom.vivo.com.br
  • usuário da APN = vivo
  • senha da APN = vivo

Para configurar eventos temporizados:

SET FREQ=transmissao_temporizada_com_ignicao_ligada:transmissao_temporizada_com_ignicao_desligada:tempo_para_entrar_modo_de_economia_de_energia:tempo_heartbeat:reservado(futura_implementacao_envio_temporizado_em_situacao_de_guincho)

Exemplo:

*SET FREQ=60:60:120:0:0*

Neste exemplo temos:

  • transmissão temporizada com ignição ligada 60 segundos;
  • transmissão temporizada com ignição desligada 60 minutos;
  • tempo para entrar em modo economia de energia 120 segundos;
  • tempo para envio de pacote HEARTBEAT desligado;
  • reservado para implementação futura de transmissão temporizada de pacote de reboque;

Para ler as configurações do comando FREQ:

*GET FREQ*

Para configurar eventos não temporizados (ângulo, distância percorrida e limite de velocidade):

SET REPORT=transmissao_mudanca_angulo:transmissao_distancia_percorrida:alerta_excesso_velocidade

Exemplo:

*SET REPORT=30:1000:120*

Neste exemplo temos:

  • transmissão por mudança de ângulo = 30 graus
  • transmissão por distância percorrida = 1000 metros
  • transmissão de evento de excesso de velocidade = 120 km/h

Para ler as configurações do comando REPORT:

*GET REPORT*

Para configurar os modos de operação:

SET MOD=modo_operacao:modo_ignicao:prioridade_envio_buffer:modo_de_transmissão:modo_supervisão_de_pacotes

Exemplo:

*SET MOD=1:0:0:0:0*

Neste exemplo temos:

  • modo de economia de energia = 1 (0 - ultra-econômico, 1 - econômico, 2 - sempre ligado);
  • modo de detecção de ignição = 0 (0 - física, 1 - Smart Ignition, 2 - Virtual por tensão);
  • modo de envio de buffer = 0 (0 - alta prioridade, 1 - baixa prioridade);
  • modo de transmissão = 0 (0 - absuluto, 1 - relativo);
  • modo de supervisão de pacotes = 0 (0 - desligado, 1 a 255 numero de pacotes para reiniciar);

Para ler as configurações do comando MOD:

*GET MOD*

Para configurar os parâmetros de alarmes de baterias:

SET BAT=tensao_bateria_baixa:reservado:reservado:reservado:reservado

Exemplo:

*SET BAT=11500:15200:3300:4200:5*

Neste exemplo temos:

  • tensão para gerar evento de bateria baixa e cortar o consumo da bateria externa = 11500 (11,5 Volts)
  • tensão para gerar evento de bateria alta = 15,200 mV (15,2V)
  • tensão para gerar evento de bateria interna baixa = 3300 mV (3,3V)
  • tensão para gerar evento de bateria interna alta = 4200 mV (4,2V)
  • atraso em segundos para envio de eventos de alerta de bateria = 5 segundos;

Para ler as configurações do comando BAT:

*GET BAT*

Para setar valores iniciais no hodometro acumulativo e horímetro:

SET ACM=hodometro_acumulativo:horimetro

Exemplo:

*SET ACM=20000:180*

Neste exemplo temos:

  • hodômetro total = 20000 metros
  • horímetro = 180 minutos

Para ler os valores setados em hodometro acumulativo e horímetro

*GET ACM*

Para configurar parâmetros do acelerômetro:

SET ACL=numero_ocorrencias_para_considerar_movimento:limite_forca_g

Exemplo:

*SET ACL=2:20*

Neste exemplo temos:

  • número de ocorrencias para considerar movimento = 2
  • limite de força G = 20 (2,0 G - é programado X10)

Para ler parâmetros de configuração do acelerômetro:

*GET ACL*

Para bloqueio e desbloqueio imediato:

SET RELAY=0_para_desativar_1_para_ativar_saida

Exemplo:

*SET RELAY=0*

Neste exemplo temos:

  • saída do rastreador = 0 (desativada)

\*para ativar a saída use (SET RELAY=1)

Para ler o estado da saída do dispositivo:

*GET RELAY*

Para configurar um valor de tensão para a ignição virtual por tensão:

SET ENGINEV=tensao_limite_para_considerar_ignicao_ligada

Exemplo:

*SET ENGINEV=13500*

Neste exemplo temos:

  • tensão limite para considerar ignição ligada = 13000 mV (13,5 Volts)

Para ler tensão configurada para ignição virtual por tensão

*GET ENGINEV*

Para configurar uma cerca virtual embarcada:

SET GF1=latitude:longitude:raio

Exemplo:

*SET GF1=33.697881:-117.764332:25500*

Neste exemplo temos:

  • latitude = 33.697881
  • longitude = -117.764332
  • raio da cerca virtual = 25500 metros ou 25,5 km

Para ler a configuração da cerca virtual embarcada

*GET GF1*

Observações

  • Servidor TrackMax para o MT2000: porta 5216 (dns.trackmax.com.br ou 35.230.168.225).
  • No exemplo do manual, a porta 80569 é maior que 65535 (inválida) e o IP secundário usa : no lugar de . — exemplo meramente ilustrativo.
  • No exemplo de ENGINEV o comando usa 13500, mas o texto do manual diz "13000 mV (13,5 Volts)" — grafado assim no original.
