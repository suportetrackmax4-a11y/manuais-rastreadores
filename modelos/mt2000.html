Configuração

Comunicação completa (APN + servidor primário e secundário)

Formato:

SET NTW=apn_da_operadora:usuario_apn:senha_apn:ip_ou_dns_servidor_primario:porta_servidor_primario:ip_ou_dns_servidor_secundario:porta_servidor_secundario

Exemplo (DNS no primário e IP no secundário — pode usar DNS ou IP em ambos):

*SET NTW=allcom.vivo.com.br:vivo:vivo:mbxlabcps.ddns.net:80569:187:11:203:81:80569*
  • APN = allcom.vivo.com.br / usuário = vivo / senha = vivo
  • DNS do servidor primário = mbxlabcps.ddns.net, porta 80569
  • IP do servidor secundário = 187:11:203:81 (grafado assim no original), porta 80569

Apenas URL primário

SET URL=ip_ou_dns_servidor_primario:porta_servidor_primario
*SET URL=mbxlabcps.ddns.net:80569*

Apenas APN

SET APN=apn_da_operadora:usuario_apn:senha_apn
*SET APN=allcom.vivo.com.br:vivo:vivo*

Eventos temporizados (FREQ)

SET FREQ=transmissao_temporizada_com_ignicao_ligada:transmissao_temporizada_com_ignicao_desligada:tempo_para_entrar_modo_de_economia_de_energia:tempo_heartbeat:reservado(futura_implementacao_envio_temporizado_em_situacao_de_guincho)
*SET FREQ=60:60:120:0:0*
  • transmissão com ignição ligada: 60 segundos
  • transmissão com ignição desligada: 60 minutos
  • tempo para entrar em economia de energia: 120 segundos
  • heartbeat: 0 = desligado
  • reservado (implementação futura: transmissão temporizada de pacote de reboque)

Eventos não temporizados (ângulo, distância, velocidade)

SET REPORT=transmissao_mudanca_angulo:transmissao_distancia_percorrida:alerta_excesso_velocidade
*SET REPORT=30:1000:120*
  • mudança de ângulo = 30 graus; distância percorrida = 1000 metros; excesso de velocidade = 120 km/h

Modos de operação (MOD)

SET MOD=modo_operacao:modo_ignicao:prioridade_envio_buffer:modo_de_transmissão:modo_supervisão_de_pacotes
*SET MOD=1:0:0:0:0*
  • modo de economia de energia = 1 (0 - ultra-econômico, 1 - econômico, 2 - sempre ligado)
  • modo de detecção de ignição = 0 (0 - física, 1 - Smart Ignition, 2 - Virtual por tensão)
  • modo de envio de buffer = 0 (0 - alta prioridade, 1 - baixa prioridade)
  • modo de transmissão = 0 (0 - absoluto, 1 - relativo)
  • modo de supervisão de pacotes = 0 (0 - desligado, 1 a 255 número de pacotes para reiniciar)

Alarmes de bateria (BAT)

SET BAT=tensao_bateria_baixa:reservado:reservado:reservado:reservado
*SET BAT=11500:15200:3300:4200:5*
  • 11500 (11,5 V): evento de bateria baixa e corte do consumo da bateria externa
  • 15200 mV (15,2 V): evento de bateria alta
  • 3300 mV (3,3 V): bateria interna baixa
  • 4200 mV (4,2 V): bateria interna alta
  • 5: atraso em segundos para envio de eventos de alerta de bateria

Hodômetro acumulativo e horímetro (ACM)

SET ACM=hodometro_acumulativo:horimetro
*SET ACM=20000:180*
  • hodômetro total = 20000 metros; horímetro = 180 minutos

Acelerômetro (ACL)

SET ACL=numero_ocorrencias_para_considerar_movimento:limite_forca_g
*SET ACL=2:20*
  • 2 ocorrências para considerar movimento; limite de força G = 20 (2,0 G — programado x10)

Bloqueio e desbloqueio imediato (RELAY)

SET RELAY=0_para_desativar_1_para_ativar_saida
*SET RELAY=0*
SET RELAY=1
  • SET RELAY=0 = saída desativada; SET RELAY=1 = saída ativada

Ignição virtual por tensão (ENGINEV)

SET ENGINEV=tensao_limite_para_considerar_ignicao_ligada
*SET ENGINEV=13500*
  • tensão limite para considerar ignição ligada: 13500 (o original escreve "13000 mV (13,5 Volts)")
  • Usar junto com SET MOD=x:2:... (ignição virtual por tensão).

Cerca virtual embarcada (GF1)

SET GF1=latitude:longitude:raio
*SET GF1=33.697881:-117.764332:25500*
  • latitude 33.697881, longitude -117.764332, raio 25500 metros (25,5 km)
