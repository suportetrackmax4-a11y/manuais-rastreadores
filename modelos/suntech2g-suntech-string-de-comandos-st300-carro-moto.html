Suntech — String de comandos (ST300, carro/moto)

  • Modelo(s): Suntech protocolo ST300 (linha ST3XX; perfil "recomendado manual ST310U")
  • Pasta: SUNTECH2G
  • Fabricante/Protocolo: Suntech — protocolo ST300
  • Arquivos-fonte: SUNTECH STRING DE COMANDOS (3).pdf
SERIAL = número de série do equipamento (ID_EQUIPAMENTO).

Consultas

Solicita posição.

Solicita configuração básica.

Solicita configuração completa.

Solicita IMSI.

Solicita ICCID.

Solicita versão.

Teste.

Configuração

Comandos gerais

ST300CMD;SERIAL;02;Reboot

Reiniciar sem apagar.

ST300CMD;SERIAL;02;Reset

Reiniciar formatando.

ST300CMD;SERIAL;02;Enable1

Bloqueio (observar lógica de ativação).

ST300CMD;SERIAL;02;Disable1

Desbloqueio (observar lógica de ativação).

ST300CMD;SERIAL;02;EraseAll

Apaga memória de posições.

ST300CMD;SERIAL;02;InitDist

Zera distância.

ST300CMD;SERIAL;02;SetOwnNo=NUMERO_CELULAR

Define número próprio (formato +55DDDNÚMERO).

ST300CMD;SERIAL;02;SetHMeter=1

Setar contador de horas trabalhadas.

ST300CMD;SERIAL;02;SetOdometer=12

Setar odômetro total.

ST300CMD;SERIAL;02;RestartAntiTheft2

Reinicia antifurto 2.

ST300CMD;SERIAL;02;ImproveBatteryLife=1

Otimização da bateria de backup.

ST300CMD;SERIAL;02;SetOdoIgn=0

Incrementação do odômetro com ignição desligada.
