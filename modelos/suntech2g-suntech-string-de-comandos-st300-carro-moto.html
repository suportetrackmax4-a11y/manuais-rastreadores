Suntech — String de comandos (ST300, carro/moto)

  • Modelo(s): Suntech protocolo ST300 (linha ST3XX; perfil "recomendado manual ST310U")
  • Pasta: SUNTECH2G
  • Fabricante/Protocolo: Suntech — protocolo ST300
  • Arquivos-fonte: SUNTECH STRING DE COMANDOS (3).pdf

Parâmetros de rede

Campos: autenticação (0 = Vivo, 1 = outros); APN; usuário; senha; IP1; porta1; IP2; porta2; número SMS (0); PIN (0).

ST300NTW;SERIAL;02;0;smart.m2m.vivo.com.br;vivo;vivo;200.98.204.151;7210;200.98.204.152;7210;0;0

Vivo Smart M2M com IP primário e secundário (exemplo do documento).

ST300NTW;SERIAL;02;0;smart.m2m.vivo.com.br;vivo;vivo;200.98.204.151;7210;;;0;0

Somente IP primário.
