Início / SUNTECH

SUNTECH (4G) — ST4315U / ST43xx

  • Modelo(s): Suntech ST4315U (linha 4G "ST43"), LTE Cat-M1 / Cat-NB / GSM
  • Fabricante / protocolo: Suntech (Suntech do Brasil) — protocolo ST4xxx com comandos CMD; / PRG; / respostas RES; / RPR;
  • Identificador: o IDENTIFICADOR do modelo possui 10 dígitos (ex.: 2180070496, ID_EQUIPAMENTO)
  • Arquivos-fonte:
    • SUNTECH/COMANDOS suntech 4g st43.txt (anotações + trecho da "DOCUMENTAÇÃO – SUPORTE SUNTECH DO BRASIL — COMANDO SMS E GPRS PARA ST4315U")
Recomendação do fabricante: ao configurar o ST4315U pela primeira vez, utilizar o perfil de configuração padrão disponibilizado no site da Suntech do Brasil.

Consultas

Configuração

APN

PRG;IDENTIFICADOR;10;00#01;01#APN;02#USUÁRIO;03#SENHA

Formato genérico: PRG;xxxxxxxxxx;10;00#Autenticação;01#apn;02#user;03#pass

PRG;ID;10;00#00;01#APN;02#user;03#pass

Campo Autenticação (conforme informação da operadora):

  • 00 = para PAP
  • 01 = para CHAP - (Recomendado se utilizar chips Getrak)
  • 02 = para automático
  • 03 = para nenhum

Campo Tipo Banda:

  • 00 = LTE Cat. M1 (4G) somente
  • 01 = LTE Cat. M1 (4G) e GSM (2G) - (Recomendado)
  • 02 = LTE Cat. NB somente
  • 03 = LTE Cat. M1 e Cat. NB
  • 04 = LTE Cat. M1, Cat. NB e GSM
  • 05 = GSM (2G) somente

Ativar sinal (anotação: "Cat-nb2-gsm"):

PRG;;10;54#04

Configuração para MOTO

PRG;Id;10;60#0;70#00
PRG;Id;19;00#02;01#0.10
PRG;Id;19;01
PRG;Id;17;01#120
PRG;Id;16;70#0
  1. Desabilita o Keep-Alive: PRG;Id;10;60#0;70#00
  2. Configura o sensor de Movimento (Choque): PRG;Id;19;00#02;01#0.10
  3. Ativa o Mode Sleep (Ultra-baixo consumo): PRG;Id;19;01
  4. Configura o tempo para entrada em modo repouso: PRG;Id;17;01#120
  5. Configura o tempo parado para 0: PRG;Id;16;70#0

Ações

Reboot:

CMD;IDENTIFICADOR;03;03

Desativa saída 1 (DESBLOQUEAR):

Ajuste de odômetro/hodômetro (metros, max: 1000000000):

Apaga posições de memória:

iButton (identificação de motorista)

iButton tem 16 dígitos. Ex.: 0200 0001 A0EE F101

Teste cadastrar iButton:

cmd;ID_EQUIPAMENTO;18;06#e100000926135101

Comando (suporte Smart Sim, 14/09/2023):

PRG;ID;18;00#A0000001874F2301;01#2222222222222222

Nos campos 00 e 01 são os IDs dos motoristas, que vão de 00 a 99; nos campos com 16 dígitos ficam os iButtons.

Consultar / cadastrar via 0514:

CMD;ID_EQUIPAMENTO;05;14
CMD;ID_EQUIPAMENTO;05;14;01#02000001A0EEF101

Controle de saída x iButton (SetDidOutCtrl):

  • Não bloqueia sem ler iButton: RES;ID_EQUIPAMENTO;04;20;0
  • Bloqueia sem ler iButton (ativa ambas Saídas 1 e 2): RES;ID_EQUIPAMENTO;04;20;1
ValorTipo de Controle de Saída
0Não ativa nenhuma saída
1Ativa ambas Saídas 1 e Saída 2
2Ativa somente Saída 2
3Ativa somente Saída 1

GetDidOutCtrl: requisita o tipo de controle de saída em relação ao ID do Motorista (iButton) configurado previamente.

Problemas e soluções

  • Chips Getrak: usar autenticação 01 (CHAP).
  • Para manter bateria principal/backup, horímetro, odômetro e timeadvance na string, enviar os comandos de informações adicionais (STT/ALT) acima.
  • Bloqueio sem iButton lido: ver RES;ID;04;20;1 / ;0.
