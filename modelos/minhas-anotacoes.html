Problemas e soluções

NÃO RECEBE SMS

  1. RESET NO CHIP (SMART OU MAX IOT)
  2. PEDIR FOTO NITIDA DO CHIP CONTENDO OS NUMEROS E INSERIDO NO RASTREADOR;
  3. PEDIR RESET FISICO;
  4. SOLICITAR LOCALIZAÇÃO DE ONDE ESTA O RASTREADOR;

ULTIMO TESTE: SOLICITAR QUE COLOQUE O CHIP M2M EM UM CELULAR PARA TESTAR SE CHEGA O SMS.

RESULTADO:

  1. SE MESMO ASSIM NÃO CHEGAR SMS O CHIP PODE ESTAR COM DEFEITO OU FALTA DE COBERTURA DA OPERADORA.
  2. SE CHEGAR SMS NO CELULAR, TENTE VOLTAR O CHIP NO RASTREADOR;
  3. SE MESMO ASSIM NÃO CHEGAR O SMS O RASTREADOR PODE ESTAR DEFEITO

ANOTAÇÕES SOBRE TOKEN (ANOTAÇÕESSOBRE TOKEN.txt)

O token quem de um celular de um usuario é uma coisa se pegar o mesmo usuario e gerar um token em outro celular, vai ser outra coisa

Não vai chegar notificação no usuario do cliente se o revenda usar o usuario do cliente para gerar o token

resumindo:

  • tem que gerar o token pelo celular do cliente
  • se gerar pelo celular do revenda, vai chegar notificação só para o revenda
