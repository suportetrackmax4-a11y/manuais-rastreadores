Início / J14 GT06

J14 GT06 (pacote de firmware)

  • Modelo(s): J14 com módulo MC20, protocolo GT06. Firmware J14_MC20_GT06_V615_20221126 (26/11/2022).
  • Fabricante/Protocolo: plataforma MediaTek MT6261 (bootloader ULTRA2503D_11C_BOOTLOADER_V005_MT6261_MAUI_11C_W13_52_SP3_V3_F29.bin), GPS MediaTek MT3333 (MT3333.bin). Protocolo GT06.
  • Arquivos-fonte: esta pasta é só ferramenta de gravação de firmware, sem manual nem comandos.
    • Lidos: output/MultiPortFlashDownloadProject.ini, output/USBSwitchTool.ini, output/BACKUP.ini, output/BACKUP.ini_backup, output/brom.ini, output/J14_MC20_GT06_V615_20221126/ULTRA2503D_11C_BB.cfg
    • Ignorados (programa, firmware ou binário): MultiPortFlashDownloadProject.exe, USBSwitchTool.exe, DualTalkSwitchTool.exe, *.dll, *.bin, ROM, VIVA, ALICE, ZIMAGE_ER, EXT_BOOTLOADER, DYNAMIC_COMP_*, MTK_DATABASE.mdb, .lib, .map, .pch, .drc, MDTDATA, manifests

Consultas

Nenhuma (não há comandos SMS nesta pasta). Veja a pasta J14 2g para os comandos do J14.

Configuração

Gravação do firmware (MediaTek MultiPort Flash Download Tool)

Configuração salva no MultiPortFlashDownloadProject.ini:

Cable=USB
Baseband chip=auto detect
External clock=26mhz
Baudrate=115200
Type=Download ROM
DA_bin=C:\Users\user\Desktop\J14 GT06\output\MTK_AllInOne_DA.bin
Format FAT range=manual
Format FAT begin address =0x03C00000
Format FAT length =0x00400000
NAND format FAT begin address =0x02000000
NAND format FAT length =0x06000000
Scatter_Folder=C:\Users\user\Desktop\VT14 GT06 - English\J14_H18_V611_20220401
OperateFlashType=NAND
USB DL With Two Site=yes
TheFirstComPortNo=4
Reset to factory default visible=yes
Com port filter=Vid_0e8d&Pid_0003&Rev_0100
DisconnectUSBComportAfterDownload=1
Preloader USB filter=VID_0E8D&PID_2000
download_retry_times=2
  • DA (Download Agent): MTK_AllInOne_DA.bin (existe também MTK_AllInOne_DA_MT3333_MP.BIN e gps_DA.bin para o GPS)
  • Pasta scatter/firmware: apontava para J14_H18_V611_20220401. Para gravar a V615, aponte para J14_MC20_GT06_V615_20221126.
  • Filtros USB MediaTek: VID 0E8D, PID 0003 (BROM) / 2000 (preloader)

Mapa de regiões do firmware (ULTRA2503D_11C_BB.cfg)

platform: MT6261
boot_region: ULTRA2503D_11C_BOOTLOADER_V005_MT6261_MAUI_11C_W13_52_SP3_V3_F29.bin, EXT_BOOTLOADER
main_region: ROM, VIVA
gps_module_region: MT3333.bin

Receitas por operadora/servidor

Nenhuma.

Problemas e soluções

  • A pasta backup/ guarda ROM.orig e VIVA.orig (cópias originais antes de uma modificação).

Ligação/LEDs

Não há informações.

Observações

  • USBSwitchTool.ini: detecta o dispositivo MediaTek (USB\Vid_0e8d&Pid_00A2&MI_01), baudrate 115200.
  • BACKUP.ini e brom.ini são padrões da ferramenta (backup e restauração de NVRAM em Z:\NVRAM\NVD_DATA\) e não têm conteúdo útil.
