Início / J14 2g

J14 2G (e J16)

  • Modelo(s): J14 2G e J16 (V2 ONEBLOCK). Firmware citado: J14_M216_GT06_V416/V417/V426.
  • Fabricante/Protocolo: protocolo GT06 (SZCS#GT06SEL=1). Padrão de configuração da Redeveiculos.com.
  • Arquivos-fonte:
    • J14 2g/Comandos J14 - J16 Padrão Redeveiculos.com (2).txt
    • J14 2g/GPS FAIL J14.txt

Consultas

SERVER#

Consulta os parâmetros do servidor.

CXZT

Configuração

SERVER,1,server11.redeveiculos.com,5023,0#

Servidor por DNS (modo 1).

SERVER,0,157.245.12.6,5023,0#

Servidor por IP (modo 0).

APN,XXXX,USER,PASSWORD#

APN, usuário e senha.

SZCS#GT06SEL=1#GT06IEXVOL=2

Seleciona o protocolo GT06 e o envio da tensão externa.

SZCS#SLPDISCONNECT=0

Não desconecta no sleep.

SZCS#SOURCE_OFF_TYPE=1

Bloqueio imediato.

TIMER,30,3600#

Tempo para carro: 30 s ligado / 3600 s desligado (mínimo 5 s, máximo 18000 s).

TIMER,60,7200#

Tempo para moto: 60 s ligado / 7200 s desligado.

RESET#

Reinicia o equipamento sem perder as configurações.

Atualização de firmware por SMS (OTA)

YCSJ,http://156.224.31.150/J14_M216_GT06_V426.bin,B1#

Atualiza para a V426.

Problemas e soluções

V2 ONEBLOCK com "GPS FAIL" (anotado como testado e funcionando)

  1. Envie o SMS para atualizar para a versão 416:
YCSJ,http://139.9.60.174/update/J14_M216_GT06_V416.bin,0B#
  1. Aguarde 5 minutos.
  2. Envie o SMS para atualizar para a versão 417:
YCSJ,http://139.9.60.174/update/J14_M216_GT06_V417.bin,A9#
  1. Aguarde 5 minutos.
  2. Zere o equipamento:
FORMAT
  1. Cheque o equipamento:
CXZT

Não há informações.

Observações

  • O último parâmetro do YCSJ (B1, 0B, A9) é o checksum do arquivo .bin. Cada versão tem o seu.
  • Para servidor por DNS use o modo 1. Para IP use o modo 0.
