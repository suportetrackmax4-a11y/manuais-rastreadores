  • Modelo: LV-12 / LV12B RK102

  • Protocolo: GT06 (indicado para o DNS TrackMax porta 5023)
  • Plataforma: TrackMax (dns.trackmax.com.br)

LV12B RK102 (arquivo COMANDOS LV12B RK102)

Servidor: dns.trackmax.com.br porta 5023 (GT06). APN ALGAR tmax.algar.br.

Atenção: o arquivo do LV-12 usa porta 2012 (SERVER,1,...) e o do LV12B RK102 usa porta 5023 (GMNET,...).

Configuração

Comando para iniciar APN

apninit#

Comando de APN

APN,tmax.algar.br,algar,algar#

DNS e PORTA TRACKMAX (GT06)

GMNET,dns.trackmax.com.br,5023#

Comando de TIMER (em segundos)

TIMER,60#

Comando de fuso horário

GMT,W,0#

Consultas

Comando para obter localização

WHERE#

Comandos de ação

Bloqueio

RELAY,1#

Desbloqueio

RELAY,0#

Reset

RESET#
