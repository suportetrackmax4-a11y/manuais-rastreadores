Problemas e soluções

Comando para forçar a conexão

clear123456
gprs123456 on
gprs123456,0,0
gprs123456

Limpa a memória, força GPRS, configura TCP e ativa GPRS.

Lembretes

  • Sempre abrir a plataforma original primeiro: se o equipamento for configurado com o IP errado, ele volta para a plataforma original.
  • Se, assim que configurar, o equipamento não subir, faça um reset para voltar de fábrica e reconfigure.
  • Sempre conferir o ID do equipamento.
