  • Fabricante/Protocolo: Jimi IoT / Concox. Comandos no padrão CMD,param#. Protocolo GT06/Concox.

Formatos de referência (vl01.txt)

ATENÇÃO: Se estiver utilizando APN privada desative a APN automática!

ASETAPN,OFF#
APN,apnname,user,pwd#
SERVER,mode,domainName/IP,port,protocol#

Para envio de dados com informações GPS, utilize o comando:

GPSDUP,ON#

Para que o terminal desligue o filtro de efeito estrela, envie o seguinte comando:

SF,OFF#

Para consulta, enviar: SF#

TIMER,T1,T2#

Para inserção de valores de odometro, o comando para sua configuração é:

MILEAGE,A,B#

Check IMEI → SIMNO#

SIMNO#

Receitas por operadora/servidor

  • TrackMax principal: dns.trackmax.com.br porta 5023 (o exemplo pela plataforma usa a porta 2502)
  • TrackMax backup: backup.trackmax.com.br porta 5023
  • Claro: APN claro.com.br

Problemas e soluções

  • APN privada: desative a APN automática com ASETAPN,OFF# antes de APN,...#.
  • Comando pela plataforma não funciona: coloque a vírgula antes do # (ex.: SERVER,1,dns.trackmax.com.br,2502,0,#).
  • Efeito estrela (posições espalhadas parado): SF,OFF# desliga o filtro. Use SF# para consultar.
