Início / LINHA TK

Linha TK (TK905 / TK915 / TK913 / TK303 / TK311)

  • Modelo(s): TK905, TK915, TK913 (TKSTAR), TK303, TK311 (e TK103 e similares com a mesma sintaxe)
  • Fabricante/Protocolo: TKSTAR / Xexun e similares. Comandos no padrão comando+senha (senha padrão 123456). Protocolo TK / TK905.
  • Arquivos-fonte:
    • LINHA TK/TK905 TK915.txt
    • LINHA TK/TREINAMENTO CONFIGURAR O TK.txt
    • LINHA TK/LEMBRETES DO TK.txt
    • Ignorado: RASTREADORES - Atalho.lnk (atalho)

Configuração

Reset / início

adminpassword13142324
clear123456
erase123456
begin123456
reset123456
  • adminpassword13142324: restaura a senha de fábrica e o equipamento (reset de senha e geral)
  • clear123456: limpa a memória
  • erase123456: formata a memória
  • begin123456: restaura o padrão de fábrica e inicia a programação (reinicia)
  • reset123456: reinicia o aparelho. No TK905 é "inicia de fábrica" e também volta para a plataforma original.

  • noschedule123456: desativa o envio depois do sleep

Problemas e soluções

  • Sempre abra a plataforma original primeiro. Se o equipamento for configurado com o IP errado, ele volta para a plataforma original.
  • Configurou e não subiu: faça um reset para voltar ao padrão de fábrica e reconfigure.
  • Não comunica (TK905): veja se está no protocolo TK905ZF690CJTS39138#240416. Se estiver, use a porta 5015 e coloque dois zeros na frente do ID (ex.: 009590027420).
  • Não conecta: rode a sequência para forçar a conexão (clear123456, gprs123456 on, gprs123456,0,0, gprs123456).
  • Sempre confira o ID do equipamento.

Ligação/LEDs

Os LEDs precisam estar piscando:

  • Laranja: GPRS/internet
  • Azul: GPS

Observações

  • Nos comandos, a senha padrão 123456 vem colada ao comando (ex.: tracker123456).
  • adminpassword13142324 é a senha mestre para restaurar a senha de fábrica.
